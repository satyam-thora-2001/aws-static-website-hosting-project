# 🚀 AWS Static Website Hosting Project

## 📌 Overview

This project demonstrates secure static website hosting using AWS services with HTTPS and custom domain integration.

## 🧱 Architecture

- Amazon S3 (Static Website Hosting)
- AWS CloudFront (CDN)
- AWS Certificate Manager (ACM SSL)
- Custom Domain Configuration
- DNS CNAME Records

## ⚙️ AWS Services Used

- Amazon S3
- AWS CloudFront
- AWS Certificate Manager (ACM)
- Custom Domain
- DNS Management

## 🔐 Security

- HTTPS Enabled Website
- SSL/TLS Certificate
- Secure Content Delivery using CloudFront

## 📈 Features

- Static Website Hosting
- Global Content Delivery
- Custom Domain Integration
- SSL Secure Website
- Fast Website Access using CDN
